# Portfolio of Awolad Hossain

This is a portfolio website built using Next.js and Tailwind CSS. It showcases my skills as a full-stack developer, including my projects, experience, and skills.

## Features

* Responsive design for various devices
* Dark mode and light mode support
* Animated sections for a smooth user experience
* SEO optimized for better search engine rankings
* Easy to navigate and find information

## Technologies Used

* Next.js for server-side rendering and static site generation
* Tailwind CSS for styling and layout
* TypeScript for type safety and better code quality
* React for building reusable UI components
* Docker for containerization and deployment
* MongoDB for storing data
* PostgreSQL for storing relational data
* Go for building scalable APIs

## How to Run Locally

1. Clone the repository using `git clone`
2. Install the dependencies using `npm install`
3. Start the development server using `npm run dev`
4. Open the website in your browser at `http://localhost:3000`

## How to Deploy

1. Build the website using `npm run build`
2. Start the production server using `npm run start`
3. Deploy the website to a hosting platform of your choice (e.g. Vercel, Netlify, etc.)
